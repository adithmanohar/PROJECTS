#  Flight Delay Prediction

##  Overview

A Machine Learning project that analyzes flight data and predicts flight delays using Python.

##  Objective

* Analyze flight-related data
* Clean and preprocess the dataset
* Identify factors affecting flight delays
* Build and evaluate a Machine Learning model

##  Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

##  Workflow

**Data Cleaning → EDA → Preprocessing → Model Training → Prediction → Evaluation**

##  Files

* `day16_flight_delay_prediction.csv` — Dataset
* `flight delay analysis.ipynb` — Jupyter Notebook
